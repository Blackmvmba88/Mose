# 🗺️ MOSE Roadmap

Esta es la hoja de ruta de MOSE, con **6 hitos clave** que guiarán su evolución.

> **Nota**: MOSE no es solo un mouse alternativo. Es un experimento sobre cómo el cuerpo puede ser una interfaz natural con la tecnología.

---

## 🎯 Milestone 1: Ecosystem Integration (v1.2.0)

**Objetivo**: Convertir MOSE en una pieza de ecosistema, no solo una aplicación final.

**Qué incluye:**
- ✅ API de eventos (`mose.events`) — **COMPLETADO en v1.1.0**
- 📦 Instalación vía `pip install mose`
- 🔌 Documentación completa de la API
- 🧪 Ejemplos de integración con otras aplicaciones
- 📚 Tutorial de uso de la API para desarrolladores
- 🌐 Publicación en PyPI oficial

**Por qué importa**: Esto permite que otros desarrolladores integren eye-tracking en sus propias aplicaciones sin reinventar la rueda.

**Estado**: 🚧 En progreso

---

## 🎯 Milestone 2: User Learning & Persistence (v1.3.0)

**Objetivo**: Que MOSE aprenda del usuario y mejore con el tiempo.

**Qué incluye:**
- 💾 Calibración persistente (guardado de perfil de usuario)
- 📈 Mejora adaptativa basada en uso
- 👤 Múltiples perfiles de usuario
- 🔄 Recalibración en segundo plano
- 📊 Métricas de precisión y rendimiento (opt-in)

**Por qué importa**: La calibración cada vez es frustrante. Un sistema que recuerda y se adapta es más humano.

**Estado**: 📋 Planeado

---

## 🎯 Milestone 3: Advanced Gestures (v2.0.0)

**Objetivo**: Expandir el lenguaje de gestos oculares más allá de "mirar y parpadear".

**Qué incluye:**
- 👁️👁️ Doble parpadeo (clic derecho o acción alternativa)
- 😉 Wink detection (guiño izquierdo/derecho)
- ⏱️ Gaze dwell (mantener la mirada = selección)
- 🌀 Patrones de movimiento ocular (círculo, línea)
- 🎨 Gestos compuestos personalizables

**Por qué importa**: Una interfaz más rica permite expresión más precisa de intención.

**Estado**: 🔮 Visión

---

## 🎯 Milestone 4: Accessibility First (v2.1.0)

**Objetivo**: Hacer de MOSE una herramienta verdaderamente accesible para personas con limitaciones motoras.

**Qué incluye:**
- ♿ Modo de accesibilidad optimizado
- 🔊 Feedback auditivo configurable
- 📐 Zonas de descanso y "dead zones"
- 🎚️ Ajustes de sensibilidad granulares
- 🌍 Soporte multi-idioma (Español, Inglés, Portugués)
- 📱 Compatibilidad con lectores de pantalla
- 🤝 Feedback directo de usuarios con necesidades específicas

**Por qué importa**: Si MOSE no sirve a quien más lo necesita, no cumple su propósito original.

**Estado**: 🎯 Prioridad alta

---

## 🎯 Milestone 5: Context Awareness (v3.0.0)

**Objetivo**: Que MOSE entienda qué estás haciendo y se adapte al contexto.

**Qué incluye:**
- 🌐 Modo navegación web (detección de enlaces, scroll)
- ✍️ Modo escritura (dictado + gaze)
- 🎨 Modo creación (diseño, dibujo, edición)
- 🎮 Modo gaming (controles adaptados)
- 📖 Modo lectura (auto-scroll, notas por mirada)
- 🤖 Integración con IA para predecir intención

**Por qué importa**: Una interfaz que se adapta al contexto es infinitamente más poderosa que una genérica.

**Estado**: 🌌 Exploratorio

---

## 🎯 Milestone 6: Neural Interface Evolution (v4.0.0+)

**Objetivo**: Explorar la frontera entre intención y acción.

**Qué incluye:**
- 🧠 Análisis de patrones cognitivos de mirada
- 🔮 Predicción de intención antes de la acción
- 📡 API de "Human Intent" (no solo eventos de mouse)
- 🌊 Detección de estados de atención/fatiga
- 🧬 Personalización basada en patrones neurológicos
- 🚀 Investigación abierta en neurotecnología accesible

**Por qué importa**: Esta es la frontera. Cuando mirar sea indistinguible de actuar, habremos expandido lo que significa "interfaz".

**Estado**: 🌠 Futuro lejano

---

## 📊 Principios del Roadmap

Este roadmap sigue tres principios:

1. **Tracción antes que features** — Cada milestone debe atraer usuarios y contribuidores reales
2. **Accesibilidad primero** — Si algo complica el uso para personas con limitaciones, no va
3. **Código abierto de corazón** — Todo avance debe beneficiar a la comunidad completa
